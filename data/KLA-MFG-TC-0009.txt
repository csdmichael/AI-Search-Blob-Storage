────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the Puma 9900 system to detect
and classify Edge Placement Error defects during post-metallization inspection
at the 3nm technology node. The test is conducted at Singapore Fab 7 to ensure
manufacturing quality standards are met for 450mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Edge Placement Error defects
that are critical to yield at the 3nm node. This test case is part of
the ongoing qualification program for the Puma 9900 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: Puma 9900
- Inspection Type: FinFET Inspection
- Target Defect: Edge Placement Error
- Process Step: Post-Metallization
- Wafer Size: 450mm
- Technology Node: 3nm
- Fab Location: Singapore Fab 7

This test case applies to all Puma 9900 systems deployed at Singapore Fab 7
for post-metallization monitoring in the 3nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                Puma 9900
Software Version:      v9.3.668
Recipe:                FINFET_INSPECTION_3nm_POST_METALLIZATION
Illumination Mode:     Brightfield
Scan Speed:            Medium (130 mm/s)
Pixel Size:            0.25μm
Edge Exclusion:        4mm
Sampling Plan:         21-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the Puma 9900 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'FinFET Inspection' recipe from the recipe library.
6. Configure detection sensitivity to target Edge Placement Error defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 3nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 87 wafers per hour
- Classification accuracy shall be ≥ 96% for known defect types
- Repeatability (3-sigma) shall be within ±1.4% for FinFET Inspection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.93 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The Puma 9900 demonstrated excellent performance
   in detecting Edge Placement Error at the 3nm node.

b) The capture rate requires optimization of the detection algorithm.

c) Nuisance rate exceeds the target threshold; recipe tuning is recommended.

d) Cross-correlation with the reference SEM confirmed classification accuracy.

e) The defect review station correlation was within specification.
