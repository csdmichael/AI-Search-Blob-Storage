────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the Teron SL650 system to detect
and classify Voids defects during post-oxidation inspection
at the 10nm technology node. The test is conducted at Milpitas Fab B to ensure
manufacturing quality standards are met for 200mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Voids defects
that are critical to yield at the 10nm node. This test case is part of
the ongoing qualification program for the Teron SL650 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: Teron SL650
- Inspection Type: Film Thickness Measurement
- Target Defect: Voids
- Process Step: Post-Oxidation
- Wafer Size: 200mm
- Technology Node: 10nm
- Fab Location: Milpitas Fab B

This test case applies to all Teron SL650 systems deployed at Milpitas Fab B
for post-oxidation monitoring in the 10nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                Teron SL650
Software Version:      v13.8.381
Recipe:                FILM_THICKNESS_MEASUREMENT_10nm_POST_OXIDATION
Illumination Mode:     Darkfield
Scan Speed:            Medium (167 mm/s)
Pixel Size:            0.1μm
Edge Exclusion:        4mm
Sampling Plan:         5-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the Teron SL650 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Film Thickness Measurement' recipe from the recipe library.
6. Configure detection sensitivity to target Voids defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 10nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 113 wafers per hour
- Classification accuracy shall be ≥ 91% for known defect types
- Repeatability (3-sigma) shall be within ±2.3% for Film Thickness Measurement
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.96 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The Teron SL650 demonstrated below-target performance
   in detecting Voids at the 10nm node.

b) The capture rate exceeded the minimum threshold, confirming system readiness.

c) Nuisance rate exceeds the target threshold; recipe tuning is recommended.

d) Minor calibration drift was detected after extended run; re-calibration resolved the issue.

e) The defect review station correlation was within specification.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Re-tune detection algorithm thresholds for Voids at 10nm node.
2. Schedule follow-up test after recipe optimization.
3. Escalate to R&D for algorithm enhancement if re-tuning does not resolve sensitivity gap.
