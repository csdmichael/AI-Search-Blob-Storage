────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the Puma 9xxx system to detect
and classify Overlay Shift defects during post-cmp inspection
at the 28nm technology node. The test is conducted at Hsinchu Fab 12 to ensure
manufacturing quality standards are met for 200mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Overlay Shift defects
that are critical to yield at the 28nm node. This test case is part of
the ongoing qualification program for the Puma 9xxx platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: Puma 9xxx
- Inspection Type: FinFET Inspection
- Target Defect: Overlay Shift
- Process Step: Post-CMP
- Wafer Size: 200mm
- Technology Node: 28nm
- Fab Location: Hsinchu Fab 12

This test case applies to all Puma 9xxx systems deployed at Hsinchu Fab 12
for post-cmp monitoring in the 28nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                Puma 9xxx
Software Version:      v9.8.392
Recipe:                FINFET_INSPECTION_28nm_POST_CMP
Illumination Mode:     Brightfield
Scan Speed:            High (63 mm/s)
Pixel Size:            1.0μm
Edge Exclusion:        3mm
Sampling Plan:         5-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the Puma 9xxx system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'FinFET Inspection' recipe from the recipe library.
6. Configure detection sensitivity to target Overlay Shift defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 28nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 80 wafers per hour
- Classification accuracy shall be ≥ 93% for known defect types
- Repeatability (3-sigma) shall be within ±1.9% for FinFET Inspection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.94 R²
