────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the Teron SL650 system to detect
and classify Extra Pattern defects during post-cmp inspection
at the 14nm technology node. The test is conducted at Milpitas Fab A to ensure
manufacturing quality standards are met for 450mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Extra Pattern defects
that are critical to yield at the 14nm node. This test case is part of
the ongoing qualification program for the Teron SL650 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: Teron SL650
- Inspection Type: Optical Overlay Metrology
- Target Defect: Extra Pattern
- Process Step: Post-CMP
- Wafer Size: 450mm
- Technology Node: 14nm
- Fab Location: Milpitas Fab A

This test case applies to all Teron SL650 systems deployed at Milpitas Fab A
for post-cmp monitoring in the 14nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                Teron SL650
Software Version:      v15.4.660
Recipe:                OPTICAL_OVERLAY_METROLOGY_14nm_POST_CMP
Illumination Mode:     Brightfield
Scan Speed:            Medium (128 mm/s)
Pixel Size:            0.5μm
Edge Exclusion:        5mm
Sampling Plan:         5-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the Teron SL650 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Optical Overlay Metrology' recipe from the recipe library.
6. Configure detection sensitivity to target Extra Pattern defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 14nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 99 wafers per hour
- Classification accuracy shall be ≥ 94% for known defect types
- Repeatability (3-sigma) shall be within ±2.3% for Optical Overlay Metrology
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.96 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The Teron SL650 demonstrated below-target performance
   in detecting Extra Pattern at the 14nm node.

b) The capture rate requires optimization of the detection algorithm.

c) Nuisance rate exceeds the target threshold; recipe tuning is recommended.

d) Edge-zone defect detection showed improved performance compared to previous revision.

e) SECS/GEM communication was verified with zero packet loss during data transfer.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Review edge-zone detection parameters for optimization.
2. Schedule follow-up test after recipe optimization.
3. Monitor performance over next 30 production days.
