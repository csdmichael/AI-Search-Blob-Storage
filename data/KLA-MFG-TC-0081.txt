────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the eDR-7100 system to detect
and classify Overlay Shift defects during post-deposition inspection
at the 14nm technology node. The test is conducted at Hsinchu Fab 15 to ensure
manufacturing quality standards are met for 450mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Overlay Shift defects
that are critical to yield at the 14nm node. This test case is part of
the ongoing qualification program for the eDR-7100 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: eDR-7100
- Inspection Type: Patterned Wafer Inspection
- Target Defect: Overlay Shift
- Process Step: Post-Deposition
- Wafer Size: 450mm
- Technology Node: 14nm
- Fab Location: Hsinchu Fab 15

This test case applies to all eDR-7100 systems deployed at Hsinchu Fab 15
for post-deposition monitoring in the 14nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                eDR-7100
Software Version:      v10.1.991
Recipe:                PATTERNED_WAFER_INSPECTION_14nm_POST_DEPOSITION
Illumination Mode:     Darkfield
Scan Speed:            Low (131 mm/s)
Pixel Size:            0.1μm
Edge Exclusion:        4mm
Sampling Plan:         21-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the eDR-7100 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Patterned Wafer Inspection' recipe from the recipe library.
6. Configure detection sensitivity to target Overlay Shift defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 14nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 51 wafers per hour
- Classification accuracy shall be ≥ 94% for known defect types
- Repeatability (3-sigma) shall be within ±1.9% for Patterned Wafer Inspection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.97 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The eDR-7100 demonstrated below-target performance
   in detecting Overlay Shift at the 14nm node.

b) The capture rate exceeded the minimum threshold, confirming system readiness.

c) Nuisance rate exceeds the target threshold; recipe tuning is recommended.

d) Minor calibration drift was detected after extended run; re-calibration resolved the issue.

e) Statistical process control charts showed stable performance over the test period.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Re-tune detection algorithm thresholds for Overlay Shift at 14nm node.
2. Schedule follow-up test after recipe optimization.
3. Escalate to R&D for algorithm enhancement if re-tuning does not resolve sensitivity gap.
