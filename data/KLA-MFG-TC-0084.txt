────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the ICOS T3/T7 system to detect
and classify Overlay Shift defects during pre-bonding inspection
at the 45nm technology node. The test is conducted at Singapore Fab 7 to ensure
manufacturing quality standards are met for 200mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Overlay Shift defects
that are critical to yield at the 45nm node. This test case is part of
the ongoing qualification program for the ICOS T3/T7 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: ICOS T3/T7
- Inspection Type: Particle Detection
- Target Defect: Overlay Shift
- Process Step: Pre-Bonding
- Wafer Size: 200mm
- Technology Node: 45nm
- Fab Location: Singapore Fab 7

This test case applies to all ICOS T3/T7 systems deployed at Singapore Fab 7
for pre-bonding monitoring in the 45nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                ICOS T3/T7
Software Version:      v8.1.302
Recipe:                PARTICLE_DETECTION_45nm_PRE_BONDING
Illumination Mode:     Darkfield
Scan Speed:            High (154 mm/s)
Pixel Size:            0.1μm
Edge Exclusion:        2mm
Sampling Plan:         5-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the ICOS T3/T7 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Particle Detection' recipe from the recipe library.
6. Configure detection sensitivity to target Overlay Shift defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 45nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 58 wafers per hour
- Classification accuracy shall be ≥ 93% for known defect types
- Repeatability (3-sigma) shall be within ±1.3% for Particle Detection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.93 R²

Result Classification: FAIL

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The ICOS T3/T7 demonstrated below-target performance
   in detecting Overlay Shift at the 45nm node.

b) The capture rate exceeded the minimum threshold, confirming system readiness.

c) Nuisance rate exceeds the target threshold; recipe tuning is recommended.

d) Throughput metrics met production requirements without sensitivity compromise.

e) SECS/GEM communication was verified with zero packet loss during data transfer.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Re-tune detection algorithm thresholds for Overlay Shift at 45nm node.
2. Schedule follow-up test after recipe optimization.
3. Escalate to R&D for algorithm enhancement if re-tuning does not resolve sensitivity gap.
