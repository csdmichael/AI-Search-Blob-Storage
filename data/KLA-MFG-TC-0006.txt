────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the Zeta-20 system to detect
and classify Edge Placement Error defects during post-anneal inspection
at the 45nm technology node. The test is conducted at Milpitas Fab B to ensure
manufacturing quality standards are met for 200mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Edge Placement Error defects
that are critical to yield at the 45nm node. This test case is part of
the ongoing qualification program for the Zeta-20 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: Zeta-20
- Inspection Type: IC Substrate Inspection
- Target Defect: Edge Placement Error
- Process Step: Post-Anneal
- Wafer Size: 200mm
- Technology Node: 45nm
- Fab Location: Milpitas Fab B

This test case applies to all Zeta-20 systems deployed at Milpitas Fab B
for post-anneal monitoring in the 45nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                Zeta-20
Software Version:      v11.9.358
Recipe:                IC_SUBSTRATE_INSPECTION_45nm_POST_ANNEAL
Illumination Mode:     Darkfield
Scan Speed:            Medium (105 mm/s)
Pixel Size:            1.0μm
Edge Exclusion:        5mm
Sampling Plan:         5-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the Zeta-20 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'IC Substrate Inspection' recipe from the recipe library.
6. Configure detection sensitivity to target Edge Placement Error defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 45nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 65 wafers per hour
- Classification accuracy shall be ≥ 97% for known defect types
- Repeatability (3-sigma) shall be within ±1.9% for IC Substrate Inspection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.95 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The Zeta-20 demonstrated below-target performance
   in detecting Edge Placement Error at the 45nm node.

b) The capture rate requires optimization of the detection algorithm.

c) Nuisance rate is within acceptable limits.

d) Minor calibration drift was detected after extended run; re-calibration resolved the issue.

e) The system successfully integrated with the factory automation host.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Review edge-zone detection parameters for optimization.
2. Schedule follow-up test after recipe optimization.
3. Monitor performance over next 30 production days.
