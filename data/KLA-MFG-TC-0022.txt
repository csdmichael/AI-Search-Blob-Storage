────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the 5D Analyzer system to detect
and classify Missing Pattern defects during post-clean inspection
at the 10nm technology node. The test is conducted at Hsinchu Fab 15 to ensure
manufacturing quality standards are met for 300mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Missing Pattern defects
that are critical to yield at the 10nm node. This test case is part of
the ongoing qualification program for the 5D Analyzer platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: 5D Analyzer
- Inspection Type: Particle Detection
- Target Defect: Missing Pattern
- Process Step: Post-Clean
- Wafer Size: 300mm
- Technology Node: 10nm
- Fab Location: Hsinchu Fab 15

This test case applies to all 5D Analyzer systems deployed at Hsinchu Fab 15
for post-clean monitoring in the 10nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                5D Analyzer
Software Version:      v11.5.355
Recipe:                PARTICLE_DETECTION_10nm_POST_CLEAN
Illumination Mode:     Darkfield
Scan Speed:            Medium (118 mm/s)
Pixel Size:            1.0μm
Edge Exclusion:        4mm
Sampling Plan:         5-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the 5D Analyzer system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Particle Detection' recipe from the recipe library.
6. Configure detection sensitivity to target Missing Pattern defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 10nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 79 wafers per hour
- Classification accuracy shall be ≥ 90% for known defect types
- Repeatability (3-sigma) shall be within ±1.5% for Particle Detection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.92 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The 5D Analyzer demonstrated acceptable performance
   in detecting Missing Pattern at the 10nm node.

b) The capture rate requires optimization of the detection algorithm.

c) Nuisance rate is within acceptable limits.

d) Minor calibration drift was detected after extended run; re-calibration resolved the issue.

e) Statistical process control charts showed stable performance over the test period.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Review edge-zone detection parameters for optimization.
2. Schedule follow-up test after recipe optimization.
3. Monitor performance over next 30 production days.
