────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the 5D Analyzer system to detect
and classify Voids defects during post-cmp inspection
at the 28nm technology node. The test is conducted at Dresden Fab 3 to ensure
manufacturing quality standards are met for 450mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Voids defects
that are critical to yield at the 28nm node. This test case is part of
the ongoing qualification program for the 5D Analyzer platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: 5D Analyzer
- Inspection Type: Macro Defect Inspection
- Target Defect: Voids
- Process Step: Post-CMP
- Wafer Size: 450mm
- Technology Node: 28nm
- Fab Location: Dresden Fab 3

This test case applies to all 5D Analyzer systems deployed at Dresden Fab 3
for post-cmp monitoring in the 28nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                5D Analyzer
Software Version:      v8.1.636
Recipe:                MACRO_DEFECT_INSPECTION_28nm_POST_CMP
Illumination Mode:     Brightfield
Scan Speed:            High (142 mm/s)
Pixel Size:            0.5μm
Edge Exclusion:        5mm
Sampling Plan:         21-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the 5D Analyzer system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Macro Defect Inspection' recipe from the recipe library.
6. Configure detection sensitivity to target Voids defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 28nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 75 wafers per hour
- Classification accuracy shall be ≥ 96% for known defect types
- Repeatability (3-sigma) shall be within ±1.2% for Macro Defect Inspection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.97 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The 5D Analyzer demonstrated excellent performance
   in detecting Voids at the 28nm node.

b) The capture rate requires optimization of the detection algorithm.

c) Nuisance rate exceeds the target threshold; recipe tuning is recommended.

d) No significant drift was observed during the test duration.

e) Recipe portability between systems at this fab was confirmed.
