────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the ICOS T3/T7 system to detect
and classify Corrosion defects during pre-diffusion inspection
at the 7nm technology node. The test is conducted at Singapore Fab 7 to ensure
manufacturing quality standards are met for 300mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Corrosion defects
that are critical to yield at the 7nm node. This test case is part of
the ongoing qualification program for the ICOS T3/T7 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: ICOS T3/T7
- Inspection Type: E-Beam Inspection
- Target Defect: Corrosion
- Process Step: Pre-Diffusion
- Wafer Size: 300mm
- Technology Node: 7nm
- Fab Location: Singapore Fab 7

This test case applies to all ICOS T3/T7 systems deployed at Singapore Fab 7
for pre-diffusion monitoring in the 7nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                ICOS T3/T7
Software Version:      v15.1.619
Recipe:                E-BEAM_INSPECTION_7nm_PRE_DIFFUSION
Illumination Mode:     Brightfield
Scan Speed:            Low (189 mm/s)
Pixel Size:            0.1μm
Edge Exclusion:        3mm
Sampling Plan:         Full wafer sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the ICOS T3/T7 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'E-Beam Inspection' recipe from the recipe library.
6. Configure detection sensitivity to target Corrosion defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 7nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 75 wafers per hour
- Classification accuracy shall be ≥ 91% for known defect types
- Repeatability (3-sigma) shall be within ±1.8% for E-Beam Inspection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.96 R²
