────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the ICOS T3/T7 system to detect
and classify Delamination defects during post-planarization inspection
at the 22nm technology node. The test is conducted at Chandler Fab 42 to ensure
manufacturing quality standards are met for 450mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Delamination defects
that are critical to yield at the 22nm node. This test case is part of
the ongoing qualification program for the ICOS T3/T7 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: ICOS T3/T7
- Inspection Type: Reticle Inspection
- Target Defect: Delamination
- Process Step: Post-Planarization
- Wafer Size: 450mm
- Technology Node: 22nm
- Fab Location: Chandler Fab 42

This test case applies to all ICOS T3/T7 systems deployed at Chandler Fab 42
for post-planarization monitoring in the 22nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                ICOS T3/T7
Software Version:      v12.2.301
Recipe:                RETICLE_INSPECTION_22nm_POST_PLANARIZATION
Illumination Mode:     Brightfield
Scan Speed:            Medium (140 mm/s)
Pixel Size:            0.25μm
Edge Exclusion:        5mm
Sampling Plan:         Full wafer sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the ICOS T3/T7 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Reticle Inspection' recipe from the recipe library.
6. Configure detection sensitivity to target Delamination defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 22nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 90 wafers per hour
- Classification accuracy shall be ≥ 96% for known defect types
- Repeatability (3-sigma) shall be within ±1.8% for Reticle Inspection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.96 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The ICOS T3/T7 demonstrated below-target performance
   in detecting Delamination at the 22nm node.

b) The capture rate requires optimization of the detection algorithm.

c) Nuisance rate is within acceptable limits.

d) Edge-zone defect detection showed improved performance compared to previous revision.

e) Statistical process control charts showed stable performance over the test period.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Re-tune detection algorithm thresholds for Delamination at 22nm node.
2. Schedule follow-up test after recipe optimization.
3. Escalate to R&D for algorithm enhancement if re-tuning does not resolve sensitivity gap.
