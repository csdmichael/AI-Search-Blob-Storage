────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the 2920 Series system to detect
and classify Delamination defects during post-anneal inspection
at the 3nm technology node. The test is conducted at Chandler Fab 42 to ensure
manufacturing quality standards are met for 300mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Delamination defects
that are critical to yield at the 3nm node. This test case is part of
the ongoing qualification program for the 2920 Series platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: 2920 Series
- Inspection Type: 3D NAND Inspection
- Target Defect: Delamination
- Process Step: Post-Anneal
- Wafer Size: 300mm
- Technology Node: 3nm
- Fab Location: Chandler Fab 42

This test case applies to all 2920 Series systems deployed at Chandler Fab 42
for post-anneal monitoring in the 3nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                2920 Series
Software Version:      v8.4.456
Recipe:                3D_NAND_INSPECTION_3nm_POST_ANNEAL
Illumination Mode:     Brightfield
Scan Speed:            Medium (163 mm/s)
Pixel Size:            0.25μm
Edge Exclusion:        3mm
Sampling Plan:         21-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the 2920 Series system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the '3D NAND Inspection' recipe from the recipe library.
6. Configure detection sensitivity to target Delamination defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 3nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 51 wafers per hour
- Classification accuracy shall be ≥ 98% for known defect types
- Repeatability (3-sigma) shall be within ±2.4% for 3D NAND Inspection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.94 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The 2920 Series demonstrated below-target performance
   in detecting Delamination at the 3nm node.

b) The capture rate exceeded the minimum threshold, confirming system readiness.

c) Nuisance rate is within acceptable limits.

d) Minor calibration drift was detected after extended run; re-calibration resolved the issue.

e) The defect review station correlation was within specification.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Re-tune detection algorithm thresholds for Delamination at 3nm node.
2. Schedule follow-up test after recipe optimization.
3. Escalate to R&D for algorithm enhancement if re-tuning does not resolve sensitivity gap.
