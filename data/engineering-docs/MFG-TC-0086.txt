────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the Archer 750 system to detect
and classify Pattern Defects defects during post-metallization inspection
at the 10nm technology node. The test is conducted at Chandler Fab 42 to ensure
manufacturing quality standards are met for 300mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Pattern Defects defects
that are critical to yield at the 10nm node. This test case is part of
the ongoing qualification program for the Archer 750 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: Archer 750
- Inspection Type: Optical Overlay Metrology
- Target Defect: Pattern Defects
- Process Step: Post-Metallization
- Wafer Size: 300mm
- Technology Node: 10nm
- Fab Location: Chandler Fab 42

This test case applies to all Archer 750 systems deployed at Chandler Fab 42
for post-metallization monitoring in the 10nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                Archer 750
Software Version:      v10.7.469
Recipe:                OPTICAL_OVERLAY_METROLOGY_10nm_POST_METALLIZATION
Illumination Mode:     Brightfield
Scan Speed:            High (114 mm/s)
Pixel Size:            1.0μm
Edge Exclusion:        4mm
Sampling Plan:         21-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the Archer 750 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Optical Overlay Metrology' recipe from the recipe library.
6. Configure detection sensitivity to target Pattern Defects defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 10nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 75 wafers per hour
- Classification accuracy shall be ≥ 91% for known defect types
- Repeatability (3-sigma) shall be within ±2.2% for Optical Overlay Metrology
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.94 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The Archer 750 demonstrated below-target performance
   in detecting Pattern Defects at the 10nm node.

b) The capture rate requires optimization of the detection algorithm.

c) Nuisance rate exceeds the target threshold; recipe tuning is recommended.

d) Throughput metrics met production requirements without sensitivity compromise.

e) The system successfully integrated with the factory automation host.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Re-tune detection algorithm thresholds for Pattern Defects at 10nm node.
2. Schedule follow-up test after recipe optimization.
3. Escalate to R&D for algorithm enhancement if re-tuning does not resolve sensitivity gap.
