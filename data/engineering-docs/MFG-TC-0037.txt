────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the C205 Broadband Plasma system to detect
and classify Haze defects during post-clean inspection
at the 45nm technology node. The test is conducted at Chandler Fab 42 to ensure
manufacturing quality standards are met for 200mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Haze defects
that are critical to yield at the 45nm node. This test case is part of
the ongoing qualification program for the C205 Broadband Plasma platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: C205 Broadband Plasma
- Inspection Type: Reticle Inspection
- Target Defect: Haze
- Process Step: Post-Clean
- Wafer Size: 200mm
- Technology Node: 45nm
- Fab Location: Chandler Fab 42

This test case applies to all C205 Broadband Plasma systems deployed at Chandler Fab 42
for post-clean monitoring in the 45nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                C205 Broadband Plasma
Software Version:      v9.4.471
Recipe:                RETICLE_INSPECTION_45nm_POST_CLEAN
Illumination Mode:     Brightfield
Scan Speed:            Low (181 mm/s)
Pixel Size:            0.1μm
Edge Exclusion:        3mm
Sampling Plan:         21-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the C205 Broadband Plasma system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Reticle Inspection' recipe from the recipe library.
6. Configure detection sensitivity to target Haze defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 45nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 77 wafers per hour
- Classification accuracy shall be ≥ 96% for known defect types
- Repeatability (3-sigma) shall be within ±0.5% for Reticle Inspection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.93 R²

7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The C205 Broadband Plasma demonstrated acceptable performance
   in detecting Haze at the 45nm node.

b) The capture rate exceeded the minimum threshold, confirming system readiness.

c) Nuisance rate is within acceptable limits.

d) No significant drift was observed during the test duration.

e) Statistical process control charts showed stable performance over the test period.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Review edge-zone detection parameters for optimization.
2. Schedule follow-up test after recipe optimization.
3. Monitor performance over next 30 production days.
