────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the ATL/LMS IPRO8 system to detect
and classify Pattern Defects defects during post-implant inspection
at the 28nm technology node. The test is conducted at Milpitas Fab A to ensure
manufacturing quality standards are met for 200mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Pattern Defects defects
that are critical to yield at the 28nm node. This test case is part of
the ongoing qualification program for the ATL/LMS IPRO8 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: ATL/LMS IPRO8
- Inspection Type: Reticle Inspection
- Target Defect: Pattern Defects
- Process Step: Post-Implant
- Wafer Size: 200mm
- Technology Node: 28nm
- Fab Location: Milpitas Fab A

This test case applies to all ATL/LMS IPRO8 systems deployed at Milpitas Fab A
for post-implant monitoring in the 28nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                ATL/LMS IPRO8
Software Version:      v15.6.969
Recipe:                RETICLE_INSPECTION_28nm_POST_IMPLANT
Illumination Mode:     Darkfield
Scan Speed:            Medium (177 mm/s)
Pixel Size:            0.25μm
Edge Exclusion:        2mm
Sampling Plan:         5-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the ATL/LMS IPRO8 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Reticle Inspection' recipe from the recipe library.
6. Configure detection sensitivity to target Pattern Defects defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 28nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 72 wafers per hour
- Classification accuracy shall be ≥ 97% for known defect types
- Repeatability (3-sigma) shall be within ±2.2% for Reticle Inspection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.93 R²

7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The ATL/LMS IPRO8 demonstrated excellent performance
   in detecting Pattern Defects at the 28nm node.

b) The capture rate exceeded the minimum threshold, confirming system readiness.

c) Nuisance rate exceeds the target threshold; recipe tuning is recommended.

d) Edge-zone defect detection showed improved performance compared to previous revision.

e) The system successfully integrated with the factory automation host.
