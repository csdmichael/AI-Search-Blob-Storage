────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the Teron 640 system to detect
and classify Edge Placement Error defects during post-metallization inspection
at the 65nm technology node. The test is conducted at Milpitas Fab B to ensure
manufacturing quality standards are met for 200mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Edge Placement Error defects
that are critical to yield at the 65nm node. This test case is part of
the ongoing qualification program for the Teron 640 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: Teron 640
- Inspection Type: Film Thickness Measurement
- Target Defect: Edge Placement Error
- Process Step: Post-Metallization
- Wafer Size: 200mm
- Technology Node: 65nm
- Fab Location: Milpitas Fab B

This test case applies to all Teron 640 systems deployed at Milpitas Fab B
for post-metallization monitoring in the 65nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                Teron 640
Software Version:      v12.9.754
Recipe:                FILM_THICKNESS_MEASUREMENT_65nm_POST_METALLIZATION
Illumination Mode:     Brightfield
Scan Speed:            High (145 mm/s)
Pixel Size:            0.1μm
Edge Exclusion:        4mm
Sampling Plan:         Full wafer sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the Teron 640 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Film Thickness Measurement' recipe from the recipe library.
6. Configure detection sensitivity to target Edge Placement Error defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 65nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 96 wafers per hour
- Classification accuracy shall be ≥ 92% for known defect types
- Repeatability (3-sigma) shall be within ±2.0% for Film Thickness Measurement
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.98 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The Teron 640 demonstrated acceptable performance
   in detecting Edge Placement Error at the 65nm node.

b) The capture rate exceeded the minimum threshold, confirming system readiness.

c) Nuisance rate is within acceptable limits.

d) Edge-zone defect detection showed improved performance compared to previous revision.

e) SECS/GEM communication was verified with zero packet loss during data transfer.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Review edge-zone detection parameters for optimization.
2. Schedule follow-up test after recipe optimization.
3. Monitor performance over next 30 production days.
