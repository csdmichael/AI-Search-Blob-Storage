────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the Zeta-388 system to detect
and classify Corrosion defects during post-clean inspection
at the 10nm technology node. The test is conducted at Singapore Fab 7 to ensure
manufacturing quality standards are met for 200mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Corrosion defects
that are critical to yield at the 10nm node. This test case is part of
the ongoing qualification program for the Zeta-388 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: Zeta-388
- Inspection Type: Optical Overlay Metrology
- Target Defect: Corrosion
- Process Step: Post-Clean
- Wafer Size: 200mm
- Technology Node: 10nm
- Fab Location: Singapore Fab 7

This test case applies to all Zeta-388 systems deployed at Singapore Fab 7
for post-clean monitoring in the 10nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                Zeta-388
Software Version:      v8.4.562
Recipe:                OPTICAL_OVERLAY_METROLOGY_10nm_POST_CLEAN
Illumination Mode:     Darkfield
Scan Speed:            Low (173 mm/s)
Pixel Size:            0.25μm
Edge Exclusion:        3mm
Sampling Plan:         9-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the Zeta-388 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Optical Overlay Metrology' recipe from the recipe library.
6. Configure detection sensitivity to target Corrosion defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 10nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 101 wafers per hour
- Classification accuracy shall be ≥ 94% for known defect types
- Repeatability (3-sigma) shall be within ±0.7% for Optical Overlay Metrology
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.99 R²

d) Cross-correlation with the reference SEM confirmed classification accuracy.

e) Statistical process control charts showed stable performance over the test period.
