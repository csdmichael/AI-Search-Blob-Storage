────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the Zeta-388 system to detect
and classify Pattern Defects defects during post-anneal inspection
at the 5nm technology node. The test is conducted at Chandler Fab 42 to ensure
manufacturing quality standards are met for 450mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Pattern Defects defects
that are critical to yield at the 5nm node. This test case is part of
the ongoing qualification program for the Zeta-388 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: Zeta-388
- Inspection Type: Macro Defect Inspection
- Target Defect: Pattern Defects
- Process Step: Post-Anneal
- Wafer Size: 450mm
- Technology Node: 5nm
- Fab Location: Chandler Fab 42

This test case applies to all Zeta-388 systems deployed at Chandler Fab 42
for post-anneal monitoring in the 5nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                Zeta-388
Software Version:      v11.8.673
Recipe:                MACRO_DEFECT_INSPECTION_5nm_POST_ANNEAL
Illumination Mode:     Brightfield
Scan Speed:            Low (135 mm/s)
Pixel Size:            0.25μm
Edge Exclusion:        2mm
Sampling Plan:         5-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the Zeta-388 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Macro Defect Inspection' recipe from the recipe library.
6. Configure detection sensitivity to target Pattern Defects defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 5nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 97 wafers per hour
- Classification accuracy shall be ≥ 96% for known defect types
- Repeatability (3-sigma) shall be within ±1.9% for Macro Defect Inspection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.94 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The Zeta-388 demonstrated below-target performance
   in detecting Pattern Defects at the 5nm node.

b) The capture rate exceeded the minimum threshold, confirming system readiness.

c) Nuisance rate exceeds the target threshold; recipe tuning is recommended.

d) Cross-correlation with the reference SEM confirmed classification accuracy.

e) SECS/GEM communication was verified with zero packet loss during data transfer.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Review edge-zone detection parameters for optimization.
2. Schedule follow-up test after recipe optimization.
3. Monitor performance over next 30 production days.
