────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the WaferSight PWG system to detect
and classify Pattern Defects defects during incoming wafer qc inspection
at the 3nm technology node. The test is conducted at Singapore Fab 7 to ensure
manufacturing quality standards are met for 450mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Pattern Defects defects
that are critical to yield at the 3nm node. This test case is part of
the ongoing qualification program for the WaferSight PWG platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: WaferSight PWG
- Inspection Type: CD-SEM Measurement
- Target Defect: Pattern Defects
- Process Step: Incoming Wafer QC
- Wafer Size: 450mm
- Technology Node: 3nm
- Fab Location: Singapore Fab 7

This test case applies to all WaferSight PWG systems deployed at Singapore Fab 7
for incoming wafer qc monitoring in the 3nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                WaferSight PWG
Software Version:      v15.5.787
Recipe:                CD-SEM_MEASUREMENT_3nm_INCOMING WAFER QC
Illumination Mode:     Darkfield
Scan Speed:            Low (120 mm/s)
Pixel Size:            1.0μm
Edge Exclusion:        5mm
Sampling Plan:         5-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the WaferSight PWG system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'CD-SEM Measurement' recipe from the recipe library.
6. Configure detection sensitivity to target Pattern Defects defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 3nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 55 wafers per hour
- Classification accuracy shall be ≥ 98% for known defect types
- Repeatability (3-sigma) shall be within ±2.2% for CD-SEM Measurement
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.96 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The WaferSight PWG demonstrated acceptable performance
   in detecting Pattern Defects at the 3nm node.

b) The capture rate requires optimization of the detection algorithm.

c) Nuisance rate is within acceptable limits.

d) Edge-zone defect detection showed improved performance compared to previous revision.

e) The system successfully integrated with the factory automation host.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Review edge-zone detection parameters for optimization.
2. Schedule follow-up test after recipe optimization.
3. Monitor performance over next 30 production days.
