────────────────────────────────────────────────────────────────────────────────
1. OBJECTIVE
────────────────────────────────────────────────────────────────────────────────

This test case validates the capability of the Surfscan SP7 system to detect
and classify Crystal Originated Particles (COP) defects during post-etch inspection
at the 7nm technology node. The test is conducted at Chandler Fab 42 to ensure
manufacturing quality standards are met for 300mm wafer production.

The primary objective is to verify that the inspection system meets the required
detection sensitivity and classification accuracy for Crystal Originated Particles (COP) defects
that are critical to yield at the 7nm node. This test case is part of
the ongoing qualification program for the Surfscan SP7 platform.

────────────────────────────────────────────────────────────────────────────────
2. SCOPE
────────────────────────────────────────────────────────────────────────────────

- Product Line: Surfscan SP7
- Inspection Type: Unpatterned Wafer Inspection
- Target Defect: Crystal Originated Particles (COP)
- Process Step: Post-Etch
- Wafer Size: 300mm
- Technology Node: 7nm
- Fab Location: Chandler Fab 42

This test case applies to all Surfscan SP7 systems deployed at Chandler Fab 42
for post-etch monitoring in the 7nm manufacturing line.
Results from this test are used to establish baseline performance metrics
and to qualify new recipe configurations.

────────────────────────────────────────────────────────────────────────────────
3. TEST CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

System:                Surfscan SP7
Software Version:      v11.9.500
Recipe:                UNPATTERNED_WAFER_INSPECTION_7nm_POST_ETCH
Illumination Mode:     Darkfield
Scan Speed:            Low (107 mm/s)
Pixel Size:            1.0μm
Edge Exclusion:        2mm
Sampling Plan:         9-point sampling

────────────────────────────────────────────────────────────────────────────────
4. TEST PROCEDURE
────────────────────────────────────────────────────────────────────────────────

1. Power on the Surfscan SP7 system and allow 30-minute warm-up period.
2. Load the calibration wafer and run the standard calibration routine.
3. Verify calibration results are within specification (±2% tolerance).
4. Load the test wafer onto the stage using the automated handler.
5. Select the 'Unpatterned Wafer Inspection' recipe from the recipe library.
6. Configure detection sensitivity to target Crystal Originated Particles (COP) defects.
7. Set scan parameters: full wafer scan with edge exclusion of 3mm.
8. Initiate the inspection run and monitor real-time defect map.
9. Upon completion, review the defect density map and classification results.
10. Export results to the factory automation system (SECS/GEM interface).
11. Compare results against the golden reference baseline.
12. Document any anomalies and generate the summary report.

────────────────────────────────────────────────────────────────────────────────
5. ACCEPTANCE CRITERIA
────────────────────────────────────────────────────────────────────────────────

- Defect detection sensitivity must meet 7nm node requirements
- False positive rate shall not exceed 5% of total detected events
- Scan throughput must be ≥ 82 wafers per hour
- Classification accuracy shall be ≥ 94% for known defect types
- Repeatability (3-sigma) shall be within ±2.9% for Unpatterned Wafer Inspection
- System uptime during test shall be ≥ 98%
- All results must be traceable through the MES integration
- Measurement correlation with reference tool shall be ≥ 0.95 R²

────────────────────────────────────────────────────────────────────────────────
7. OBSERVATIONS AND FINDINGS
────────────────────────────────────────────────────────────────────────────────

During the execution of this test case, the following observations were noted:

a) The Surfscan SP7 demonstrated below-target performance
   in detecting Crystal Originated Particles (COP) at the 7nm node.

b) The capture rate exceeded the minimum threshold, confirming system readiness.

c) Nuisance rate exceeds the target threshold; recipe tuning is recommended.

d) Throughput metrics met production requirements without sensitivity compromise.

e) SECS/GEM communication was verified with zero packet loss during data transfer.

────────────────────────────────────────────────────────────────────────────────
8. CORRECTIVE ACTIONS (if applicable)
────────────────────────────────────────────────────────────────────────────────


The following corrective actions are recommended:

1. Re-tune detection algorithm thresholds for Crystal Originated Particles (COP) at 7nm node.
2. Schedule follow-up test after recipe optimization.
3. Escalate to R&D for algorithm enhancement if re-tuning does not resolve sensitivity gap.
